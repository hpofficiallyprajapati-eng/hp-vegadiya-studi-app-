HP VEGADIYA STUDY APP - PWA starter

આ ZIP માં index.html અને PWA માટે manifest, service worker અને icons છે.

મહત્વપૂર્ણ:
- આ PWA-ready વેબ એપ છે; APK અથવા Windows EXE હજી નથી.
- મોબાઇલ/લેપટોપમાં Install વિકલ્પ મેળવવા માટે HTTPS પર હોસ્ટ કરવી પડશે.
- Hosting પછી Chrome/Edge માં URL ખોલો અને Install app પસંદ કરો.
- Android APK બનાવવા માટે પછી hosted URL ને PWABuilder જેવા પેકેજરથી Android packageમાં ફેરવી શકાય.
- Google Fonts માટે ઇન્ટરનેટ જોઈએ; એપનું બાકી cached HTML offline ખૂલી શકે, પરંતુ બહારની વેબ લિંક્સ/YouTube માટે ઇન્ટરનેટ જોઈએ.
